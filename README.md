🚀 FlipZo – Smart Marketplace with AI Assistance

FlipZo is a modern full-stack marketplace application built using the MERN stack, designed to simplify the process of buying and selling pre-owned products. It goes beyond a typical marketplace by integrating AI-powered assistance to help users make smarter decisions.

💡 Key Features
🛒 Buy & Sell Products
Users can list their old products and explore items posted by others.

🤖 AI Chat Assistant
An intelligent AI assistant helps users:
Understand product quality
Evaluate whether the price is fair
Get quick insights before making a purchase

🔐 Secure Authentication System
User Signup & Login
OTP Generation & Verification
Email Verification for account security

🎨 Modern UI & Animations
Built with Material UI for clean and responsive design
Smooth animations using GSAP

⚙️ Tech Stack
Frontend: React.js, Material UI
Backend: Node.js, Express.js
Database: MongoDB
Authentication: OTP & Email Verification
AI Integration: Smart chat-based assistance
Other Tools: GSAP, REST APIs

🎯 Project Goal
The goal of FlipZo is to make second-hand buying and selling more intelligent, reliable, and user-friendly by combining a traditional marketplace with modern AI capabilities.

🚀 Future Improvements
💬 Real-time chat between buyers & sellers
⭐ Product reviews & ratings
📍 Location-based product discovery
💳 Secure payment integration
